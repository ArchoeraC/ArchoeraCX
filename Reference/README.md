# Reference

只读参考目录。**这里的任何内容都不参与构建，也不进入发布物。**

```
Reference/
├─ upstream/      # 第三方仓库浅克隆（.gitignore，不入库）
├─ notes/         # 自己的观察笔记（唯一建议入库的部分）
└─ MANIFEST.md    # 第三方仓库的 commit / 许可证 / 用途
```

## 规则

1. `upstream/` 只放第三方源码，不做修改、不提交。
2. 结论写进 `notes/`，用自己的话记录来源（项目 + commit + 文件路径）。
3. 不复制源码片段、注释、文案、图标、字体或翻译文件。
4. 闭源软件的反编译产物、二进制样本和分析材料只放本地 `.local/`，不进入公开仓库。
5. 更新参考仓库时同步更新 `MANIFEST.md` 的 commit 与许可证哈希。

参考项目只读；不得复制代码、文案、图标、字体或闭源软件的反编译产物。
