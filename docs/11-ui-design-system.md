# 11 · UI 设计系统与 AppShell 规范

> **状态**：Draft v1 · 2026-10-20；**Phase 1 已落地**（AppShell + 5 个页面骨架 + 设计令牌）
> **定位**：Flutter UI 的设计契约。实现以本文的 token、布局和组件规则为准。
> **参考**：仅使用原创设计与通用视觉原则；不包含第三方闭源软件的资产或分析材料。
> **边界**：LauncherX / BakaXL 等仅作为高层布局与信息架构参考；**不复制**其代码、XAML、图标、插画、文案、字体或像素级布局。

---

## 0. 设计立场

ArchoeraCX 的 UI 目标不是“像 LauncherX”，而是：

> **干净、留白、有层次、可长时间使用；背景可以有个性，但内容永远优先。**

我们借鉴 LauncherX 的四件事：

1. **令牌化主题**：颜色/字号/动效/阴影不散落在页面里。
2. **窗口级层次**：标题栏、导航、内容、底栏、浮层各司其职。
3. **背景图层栈**：纯色/图片/Mica/Acrylic + 装饰形状，但始终可退化为纯色。
4. **克制的动效**：页面切换与列表反馈短、轻、可关闭。

我们**不**做：

- 像素级复刻 LauncherX 的任何页面；
- 使用 DINPro 或 LauncherX 的图标/插画/文案；
- 把品牌色定成 LauncherX 的黄色；
- 为了“像”而牺牲可读性、性能或跨平台一致性。

## 1. 视觉方向

| 关键词 | 落地 |
|---|---|
| 干净 | 大面积留白、低对比度分隔线、少量边框 |
| 层次 | 背景 → 平铺区块 → 浮层，最多 3 层 |
| 轻量 | 阴影少而软；优先用背景色差而不是重阴影 |
| 个性 | 背景图/装饰形状可选（当前为纯色）；默认仍可读 |
| 克制 | 动效 120–240ms；不做弹跳、闪烁、夸张缩放 |
| 可退化 | Mica/Acrylic/模糊失败时回退纯色，不白屏 |

**默认品牌色**：`#4F7CFF`（Archoera Blue）。
LauncherX 的暖黄只作为“可选主题”存在，不作为默认品牌识别。

| `bg` | `#F7F8FB` | `#10141B` | 窗口底色 |

| `surface3` | `#E8EBF3` | `#27313F` | 浮层/输入框 |
| `textPrimary` | `#111827` | `#F2F5FA` | 标题/正文 |
| `textSecondary` | `#4B5563` | `#AAB5C6` | 说明 |
| `textTertiary` | `#8A94A6` | `#738094` | 辅助/占位 |

| `overlay` | `#00000066` | `#000000A6` | 遮罩 |

> 页面不得直接写十六进制颜色；必须引用 token 或 `ColorScheme`。

### 2.2 字号与字重

| 令牌 | 字号/行高 | 用途 |
|---|---|---|
| `display` | 32 / 40 | 首页大标题、空态主标题 |
| `title1` | 24 / 32 | 页面标题 |
| `title2` | 18 / 26 | 区块标题 |
| `body` | 14 / 22 | 正文 |
| `bodyStrong` | 14 / 22 · 600 | 强调正文 |
| `caption` | 12 / 18 | 辅助说明、元信息 |
| `overline` | 11 / 16 · 600 · 0.6 | 分组标签、chip |

- 默认字体：**Noto Sans SC Medium**（OFL，随应用打包）。
- 所有正文、标题、按钮默认使用 `FontWeight.w500`；层级靠字号、颜色和间距表达，不依赖粗体。
- 拉丁与中文统一使用 Noto Sans SC，避免中英文回退字体不一致。
- **不使用 DINPro**。
- 数字/路径/哈希：等宽字体（`JetBrains Mono` 或系统 monospace）。

### 2.3 间距

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`

| 场景 | 值 |
|---|---|
| 图标与文字 | 8 |
| 区块内边距 | 16–24 |
| 行内边距 | 8–12 |
| 页面边距 | 32（窄屏 16–24） |
| 区块间距 | 16–24 |

### 2.4 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `radiusS` | 2 | chip、输入框、状态标签 |
| `radiusM` | 4 | 按钮、可点击行 |
| `radiusL` | 4 | 浮层 |
| `radiusXL` | 6 | 对话框 |
| `bevelS` / `bevelM` / `bevelL` | 8 / 14 / 22 | 面板与弹窗的斜切角 |
| `radiusFull` | 999 | 仅头像/进度条等天然圆形 |

> 页面级分组优先使用**直边 + 斜切角（钝角）+ 1px 分隔线**，不使用装饰性圆角卡片。斜切角用于 Hero、快捷条、实例块和弹窗；按钮只保留 2–4px 小圆角。

### 2.5 阴影与边框

- 优先边框 + 背景差；阴影只用于浮层/下拉/任务中心。
- Light：`0 8 24 rgba(17,24,39,0.08)`；Dark：`0 8 24 rgba(0,0,0,0.35)`。
- 页面区块默认无填充、无阴影；用 1px 上下分隔线建立层次。
- 列表行 hover 只改 `surface2`，不做位移、不缩放。

### 2.6 动效

| 令牌 | 值 |
|---|---|
| `fast` | 120ms |
| `normal` | 180ms |
| `slow` | 240ms |
| `curve` | `Curves.easeOutCubic` |
| `curveIn` | `Curves.easeInCubic` |

规则：

- 页面切换：淡入 + 8px 上移，180ms。
- 底部导航选中：背景/文字颜色过渡 120ms。
- 列表 hover：只改背景/边框，不位移、不缩放。
- 弹层：120ms 淡入 + 轻微上移。
- 提供“减少动画”开关；关闭后只保留淡入淡出。
- 启动动画：首帧在 shell 之上播放约 1.2s 的线框动画（四角取景框逐段出现、菱形核心用线条描绘、强调色线段沿菱形移动），不插入 logo 图片或品牌文字；shell 同时在其下构建，动画结束淡出，减少动效时直接跳过。
- 不在动画中改变 `width/height/margin`，优先 `opacity/transform`。

**着色器边界**（`app/shaders/`，由 `flutter: shaders:` 编译，`AppShaderScope` 在路由之上加载一次并共享）：

| 着色器 | 用途 | 开销 | 回退 |
|---|---|---|---|
| `transition.frag` | 旧页面/旧分区快照的溶解遮罩 | 只写 alpha，单层遮罩，不新增内容层 | 普通淡出 |
| `glow.frag` | 可点击面板的指针跟随强调光 | 单面板一次径向衰减，无模糊/离屏 | InkWell 悬停底色 |

- 切页快照用 `RenderRepaintBoundary.toImageSync`：纹理在栅格线程生成，不做 GPU→CPU 回读；`toImage` 的整页回读曾是每次切页最明显的一次卡顿。
- 页面↔页面用溶解揭示新页面；首页进出仍是覆盖/收回，与 §3.1 的窗口结构一致。
- 设置分区切换把旧分区快照成纹理再溶解，同一时刻只有一棵设置子树参与布局和绘制。
- 任一程序加载失败只关闭对应效果（布局不变），减少动效或系统 `disableAnimations` 时全部回到静态实现。
- 不在每帧创建 `FragmentShader`、不逐帧 `setState`、不在动画里改布局。
- 窗口背景不参与着色器：只用 `tokens.bg` 纯色，没有渐变、光晕或逐帧重绘。

## 3. 窗口结构

### 3.1 桌面主窗口

```
┌────────────────────────────────────────────────────────────────────┐
│ TopBar     品牌                                                 48     │
├────────────────────────────────────────────────────────────────────┤
│ Content    页面标题 + 操作区                                       │
│            max-width 1400，页面切换淡入 + 8px 上移                │
│            平铺区块 / 表格行 / 列表 / 空态（直角 + 分隔线）        │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│ CommandBar 主导航（左） · 账户 + 启动（右，首页隐藏启动）    60     │
└────────────────────────────────────────────────────────────────────┘
```

- 主窗口采用**全宽底部命令栏**，高度 60；首页隐藏底栏启动按钮，使用 Hero 启动入口；其他页面保留账户 + 启动。
- 首页 → 其他页面：新页面自下而上覆盖旧页面快照。
- 其他页面之间：新页面轻微上浮，旧页面快照用 `transition.frag` 溶解淡出（无着色器时退化为淡出），不使用全屏覆盖。
- 切回首页：旧页面快照向下收回，露出首页。
- 顶部 Logo/标题栏固定，作为动画上边界。
- 页面标题放在内容区；TopBar 只保留品牌（图标 + 应用名，应用名使用当前主题强调色，随系统/自定义主题色变化），不放置占位任务/通知等调试入口。
- 导航选中态由一块**滑动的斜切底板**标记：`accentSoft` 填充 + 1px 强调色边，图标/文字在 120ms 内过渡到强调色，底板在 180ms `easeOutCubic` 内滑到新项并同步收放宽度；窗口重排只落位不滑动。主页项不参与高亮（首页本身就是画布），不使用圆角底板，也不给每个项各画一条下划线。
- 顶栏与页面同底色、不加下划线，品牌与任务按钮直接浮在内容上方；底栏在首页与页面同色（高度 46），进入其他页面后过渡为半透明 `surface1` + 1px 顶部分隔线（高度 60）。
- 命令栏左侧是主导航，右侧是账户与启动按钮；当前实例只作为启动目标，不再占用底栏。
- 宽屏显示账户名与导航文字；窄屏收成图标，超窄屏只保留账户头像和启动图标。
- 全屏/超宽窗口：内容区满宽（仅保留 32px 页边距，>2880 才封顶），顶部栏与底部命令栏使用相同边距；不再出现居中窄列与大面积两侧留白。
- 页面在宽窗口下利用横向空间：实例页切换为 2/3/4/5 列卡片网格（按实例数量铺满一行）、设置页内容区最宽 1500 且各分区（含外观）统一单列、Wiki 动态在 ≥1200/≥2100 时拆成 2/3 列、账户页在 ≥1400 时当前账户与账户列表左右并排、首页最近实例按实际数量铺满一行。
- **Phase 1** 使用系统窗口装饰；后续接 C++/平台能力后再做无边框与 Mica/Acrylic。

### 3.1.1 页面布局

| 页面 | 布局 |
|---|---|
| Dashboard | 快速启动 Hero + 单行快捷入口 + 最近实例网格；不展示核心/Java 调试卡 |
| Instances | 页头“刷新”按钮（`instance.sync`：扫描实例根、采纳/更新/标记缺失，完成后提示并刷新列表与选中项）；搜索/计数栏 + 实例列表；宽窗口（≥1020/1500/1850/2200）自动切换为 2/3/4/5 列卡片网格，卡片保留 Launch 与“更多”；每行“更多”提供实例设置（每实例覆盖）、加载器安装/更新、Mod 管理（启停/删除）；删除实例先确认一次，“同时删除本地文件”默认不勾选，勾选后必须再确认一次（二次弹窗列出将被永久删除的目录）；实例「更多」菜单另含「打开实例目录」（`system.revealPath`）与「复制实例」（默认名「<名称> 副本」，可改，成功后提示并刷新列表）；`overrides` 非空时列表/卡片显示小标记（tooltip「已覆盖全局设置」）；创建实例时加载器与版本使用左右两栏选择（左：原版/Fabric/Quilt/Forge/NeoForge，右：可搜索的版本列表），选原版时整个弹窗收窄、右栏消失；整合包安装创建的实例同样默认版本隔离 |
| Download | 来源选择 + 分类 Tab + 搜索/结果区，内容区独立滚动；项目行显示图标/统计/标签，结果支持排序、自动分页和图片预览；点开项目进入独立整页（概览/画廊/描述 + 兼容版本列表，宽窗左右两栏、窄窗单列），返回后搜索词、结果与滚动位置保留；安装提交后台任务后留在项目页提示，队列条始终在下载页底部 |
| Accounts | 当前账户 Hero + 全宽账户列表；空态合并为单个添加账户面板 |
| Wiki | 顶部机器负载面板（CPU/内存/磁盘/启动器四项指标 + 3px 比例条 + 系统运行时长，由 C++ 每 5 秒推送） + 社区动态单列流（来源健康 chip + 时间/来源/版本元信息行）；宽屏指标四列、窄屏两列或一列 |
| Settings | 左侧分区导航 + 右侧平铺设置组（外观 / 启动 / 高级 / 下载 / 存储 / Java / 任务与日志 / 通知 / 关于）；启动分区提供启动器行为、附加游戏参数、生命周期命令、包装命令与环境变量；高级分区集中放窗口模式/尺寸、Linux 性能预设、Java/内存/GC/JVM 默认值与原生库开发者选项；Java 分区只保留运行环境入口并链接到高级分区；窄屏切为顶部横向 Tab（可横向滚动） |
| Java（子页） | 返回按钮 + 页头（标题/副标题/安装 Java/重新扫描）→ 当前选择面板（自动开关、当前版本）→ 搜索与添加目录/可执行文件 → 全部 Java 运行环境平铺网格（版本徽标、厂商/架构/来源、使用中标记）；宽屏两列、窄屏一列 |
| Task center | 标题栏右上角任务入口；展示运行中/已完成任务、字节进度、速度、当前文件与取消操作；任务面板不占页面路由 |

| 路由 | 页面 | 主要内容 |

| `/instances` | Instances | 实例列表、筛选、创建/导入入口 |
| `/download` | Download | 版本、全局 Mod、整合包、资源包、光影（Tab） |

### 3.3 底栏 CommandBar

- 左：六个主导航项（主页/实例/下载/账户/Wiki/设置），图标 + 文字；选中项由一块滑动的斜切底板标记（见 §2.6/§3.1），底板填充 `accentSoft` 并带 1px 强调色边；主页项只参与导航，不显示选中、悬停或按下的底色高亮。
- 右：当前账户头像/名称 + 启动按钮，中间用 1px 竖线分隔。
- 当前实例不再显示为独立 chip；未选择实例时启动按钮进入实例页。已选实例时，启动按钮的悬浮提示显示「启动「实例名」」（窄屏图标模式下同样可见），避免误启动到别的实例。
- 窄屏只保留导航图标、账户头像与启动图标；所有图标按钮带 tooltip。
- 启动按钮在未选实例时仍可点击，但不会做成无反馈的死按钮。
- 首页隐藏启动按钮；进入/离开首页时按钮按 `AppMotion.normal` 横向展开收起并淡入淡出（`AnimatedSwitcher` + `SizeTransition`），与底栏高度动画同步，不得瞬间出现或消失。

### 3.4 托盘与关闭行为

- 托盘图标使用 `assets/branding/tray_icon.png`（32×32 PNG）；Windows 托盘只接受 PNG，右键菜单必须在代码里显式 `setContextMenu`，否则图标可见但菜单不出现。
- 关闭窗口默认退出应用；在外观 → 界面开启「关闭窗口时最小化到托盘」（`shared_preferences` 的 `ui.closeToTray`，默认关闭）后，点关闭只隐藏主窗口，下载与后台任务继续。
- 托盘菜单固定两项：「显示主窗口」恢复并聚焦窗口，「退出」走正常收尾流程。
- 托盘与窗口由 Flutter（`tray_manager` + `window_manager`）负责，不经过 C#/ABI。

## 4. 背景系统

### 4.1 图层

```
L0 窗口底色（纯色 tokens.bg）
L1 装饰形状（可选，当前未启用）
L2 内容底板（半透明/纯色）
L3 列表/浮层
L4 浮层（对话框/任务中心/通知）
```

### 4.2 类型

| 类型 | 实现 | 回退 |
|---|---|---|
| 纯色（当前） | token `bg`，L0 只画一层 `ColoredBox` | — |
| 渐变 | 2–3 个低饱和 radial/linear | 纯色 |
| 图片 | 解码到接近窗口尺寸，缓存 | 纯色 + 占位 |
| Mica | Windows DWM（Phase 2） | 半透明/纯色 |
| Acrylic | Windows/Linux 合成器（Phase 2） | 半透明/纯色 |

- 背景图不直接铺 4K；先缩小解码。
- 模糊只在背景切换/窗口尺寸变化时重算，不每帧做。
- 浅色主题叠加图片时必须加蒙版/提高内容底板不透明度，保证正文对比度 ≥ 4.5:1。
- 当前发行版只用纯色 `tokens.bg`：顶栏、页面底板与首页底栏共用同一颜色，不做渐变、光晕或实时模糊。

### 4.3 图片取色（Phase 3）

- 缩放到 64×64 后量化；
- 过滤过亮/过暗/低饱和；
- 按“人口 × 对比度”评分选主色；
- 派生 hover/pressed/soft/onAccent；
- 失败时回退品牌色，并提示“无法从图片取色”。

## 5. 组件规范

### 5.1 按钮

| 类型 | 用途 | 规则 |
|---|---|---|
| Primary | 启动、安装、确认 | 强调色填充；高度 40–44 |
| Secondary | 取消、次要操作 | `surface2` + 边框 |
| Ghost | 标题栏/列表操作 | 透明背景，hover 才出现 |
| Danger | 删除/清空 | `danger` 文本或填充；二次确认 |

- 图标按钮必须有 tooltip。
- 禁用态保持可读；用说明代替“灰掉不解释”。

### 5.2 区块与分隔线

- 页面级内容使用 `AppSection`：透明背景、直角、上下 1px 分隔线。
- 只在浮层、对话框、输入控件和状态标签上使用圆角。
- 多列信息用竖分隔线组织，不嵌套卡片。
- 区块内边距 16–24；标题与内容间距 8–12。

### 5.3 列表项

- 高度 56–72；左侧图标/头像，中间标题+副标题，右侧状态/操作。
- 选中：`accentSoft` 背景 + `accent` 左边 2px 指示条。
- hover：`surface2`。
- 不做整行缩放。

### 5.4 骨架屏

- 用于实例列表、搜索结果、下载队列。
- 形状与最终内容一致； shimmer 缓慢、低对比。
- 超过 300ms 才显示，避免闪烁。

### 5.5 空态 / 错误态

```
[图标]
主标题（一句话）
说明（为什么 + 下一步）
[主操作] [次操作]
```

- 错误态必须包含：原因、可重试动作、查看日志/诊断入口。
- 不用只弹 toast 处理页面级错误。

### 5.6 下拉选择

- 设置页和实例设置弹窗的紧凑下拉统一使用 `AppDropdown`（`lib/widgets/common/app_dropdown.dart`）：`surface2` 填充、1px `border`、`radiusM`、自带 `AppIcons.chevronDown`；弹出层由 `PopupMenuButton` 绘制并复用 `popupMenuTheme` 的 `surface1`、`bevelL`/`bevelS` 斜切、1px 边框和阴影，位置/键盘行为与动作菜单一致。
- 所有弹出菜单显式使用 `Clip.antiAlias`（`AppDropdown`、`AppDropdownFormField`、`AppMenuButton`、右键 `showMenu`），把 hover/选中高亮裁到斜切形状内，避免 Flutter 默认高亮越过菜单边缘。
- 表单内的下拉统一使用 `AppDropdownFormField`（同一文件）：保留 `InputDecorationTheme` 的标签/边框，同时共享同一弹出层、颜色和语义 chevron；不保留 Flutter 默认下划线或默认箭头。
- 创建实例、加载器安装、日志文件选择等弹窗/工具栏下拉也走上述组件，不再出现透明无边框的 `DropdownButton` 或默认 Material 菜单。
- 动作菜单（实例「更多」、账户操作、下载排序）统一使用 `AppMenuButton`（`lib/widgets/common/app_menu_button.dart`）+ `AppMenuEntry`；右键菜单复用 `appMenuEntries`，因此工具栏、右键和斜切弹出层不会各写一套。
- Java 运行时选择器也走 `AppMenuButton` 的 `itemBuilder`，只自定义“版本 + 路径 + 扫描状态”行内容，按钮和菜单位置仍与其它菜单共用。

### 5.7 任务中心

- 右侧抽屉（点击标题栏任务按钮从右滑入，Esc/遮罩关闭）；不占页面路由。
- 每个任务：图标、标题（`类别 · 具体目标`）、阶段、进度、速度、取消。
- 只记录长任务（`download.execute`、`version.plan/commit`、`loader.plan/commit/repair/autoRepair`、`modpack.*`、`launch.prepare/start`）；`settings.get`、`instance.list`、`resource.search` 这类短调用不进入列表。
- 下载页底部的队列条是任务中心的快捷入口，只显示进行中的 `download.execute` / `modpack.install*`（活动数、合计进度、合计速度），空时整条收起；两者读同一份任务状态，不额外轮询。
- 失败任务：错误码 + 重试 + 查看日志。
- 任务完成后保留最近 N 条，可清理；完成态保留最后一次进度字节数。

### 5.8 游戏日志查看器

- 入口：实例行「更多」菜单 → 查看日志；也可从任务中心的失败任务进入（后续）。
- 顶部：实例名 · 游戏版本 · 加载器 + 运行状态徽标（运行中/已结束）、强制终止（仅运行中）、刷新、关闭。
- 强制终止：运行中时标题栏出现危险色终止按钮；连续两次确认（第一次说明未保存进度可能丢失，第二次为最终确认并显示 pid）后才调用 `launch.stop`，由 C# 结束它自己启动的进程树，UI 无法指定任意 pid。
- 工具行：日志文件下拉（文件名 + 大小，运行中的文件标记 active）、跟随开关（仅运行中可用）、清理旧日志、复制全部；标题栏提供“打开日志目录”（`system.revealPath`）。
- 正文：等宽字体逐行渲染，`ERROR/FATAL/SEVERE/Exception` 用危险色、`WARN` 用警告色、堆栈行用三级文字色；默认自动滚到底，用户上滚后停止自动跟随。
- 只显示尾部（默认 400 行、256 KiB 窗口）；被裁剪时提示「仅显示最后 N 行」。
- 日志落盘有界：每个实例只保留最近 10 次启动，总量 ≤ 32 MiB，下次启动时清理最旧文件；单次日志超过 64 MiB 停止写入并留下截断标记。工具行下方显示当前占用与保留数量。
- 数据全部经 `launch.logs` / `launch.log.read` / `launch.log.tail`，UI 不读文件、不轮询；运行中由 C# 通过 ABI 进度回调推送新行。

### 5.9 对话框 / 通知

- 危险操作：标题、影响说明、确认短语/勾选、主次按钮同视觉权重。
- 通知：右下角，3–5s 自动消失；错误通知不自动消失。
- 不用全屏遮罩做普通提示。

### 5.10 Wiki 页

- 结构：页头（标题 + 副标题 + 刷新）→ 机器负载面板 → 社区动态列表；不使用左右双栏，窄窗口也不会挤成半宽。
- 机器负载：四项指标（CPU / 内存 / 磁盘 / 启动器）在 720px 以上排四列、380–720px 排两列、更窄排一列；每项为「标签（11px 三级文字）→ 22px 数值（等宽数字）→ 说明 → 3px 比例条」。数值来自 C++ 原生采样：进入页面时请求一次快照，随后由 `system.status.watch` 每 5 秒推送域事件更新；右上角标注「每 5 秒自动更新」，手动刷新仍可立即取一次。
- 比例条按占用着色：< 75% 强调色、≥ 75% 警告色、≥ 92% 危险色；启动器项是绝对占用（MB），不画比例条。
- 未知指标显示 `—`，不显示 0%；平台不支持的值由 C# 写 null，UI 隐藏对应行。
- 社区动态：单列时间倒序；每行「来源 · 类型 · 相对时间」元信息行 + 标题（最多 2 行）+ 摘要（最多 2 行）+ 作者/版本标签；有链接的行整行可点，右上角 15px 外链图标。
- 来源健康：标题下方一行 chip（来源名 + 条数）；失败源显示「不可用」并用危险色，tooltip 给出错误码；其余来源照常展示。
- 刷新：页头右侧按钮同时刷新负载与动态；不使用定时器轮询，进入页面时由 provider 拉取一次。
- 时间显示：1 分钟内「刚刚」、1 小时内分钟、24 小时内小时、7 天内天数，更早显示 `YYYY-MM-DD`。

## 6. 页面草案

### 6.1 Dashboard

- 顶部：大面积快速启动 Hero（实例名、版本/加载器/Mod/最后游玩、启动/查看全部）。
- 快捷条：当前账户、实例数量、浏览内容，三个入口共用一条直线分隔带。
- 最近实例：最多 4 个斜切角实例块，点击切换当前实例；不再堆叠工作区/账户/快捷操作三列。
- 不展示核心桥接、Java 扫描等调试卡片；Java 管理留在设置页。
- 空态：创建实例 / 导入整合包。

### 6.2 Instances

- 顶部：搜索、筛选（版本/加载器）、排序、创建/导入。
- 列表/网格切换；默认列表。
- 创建实例：默认勾选版本隔离（数据落在 `versions/<name>`，库/资源与游戏根共享）；游戏版本下拉 + 两栏加载器选择；左栏为加载器类型（含原版，选中项显示当前版本），右栏为可搜索、虚拟滚动的版本列表（最新/推荐/测试标签）。选择原版时整个弹窗（含表单宽度）以约 260ms 的宽度动画收窄到单栏，右栏消失、加载器列表铺满并显示“不安装加载器”的说明；切回加载器时弹窗整体展开；版本列表支持连续输入过滤并自动滚动到当前选中项。
- 每项：图标、名称、版本、加载器、Mod 数、最后游玩、启动/更多。
- 实例设置：实例行「更多 → 实例设置」打开弹窗，首行为实例名称（`instance.update`，仅改启动器显示名称，不移动游戏目录），其余按 内存（最小/最大）、GC（预设）、JVM 参数、游戏参数、Java（固定路径）、窗口（宽/高/全屏）分组；字段留空 = 跟随全局设置，不写入 `overrides`。保存走 `instance.update` 的 merge patch，成功后 Toast 提示并刷新实例列表与选中项。
- 覆盖标记：实例 `overrides` 非空时，列表行/卡片在名称旁显示一个小标记，tooltip「已覆盖全局设置」；标记只提示存在实例级覆盖，不展开具体字段（字段在实例设置里看）。
- 打开实例目录：实例行「更多」菜单提供「打开实例目录」，经 C++ `system.revealPath` 调系统文件管理器（Linux FileManager1，回退 Portal；Windows/macOS 原生）；目录不存在或平台拒绝打开时用 Toast 说明，不静默失败。
- 复制实例：实例行「更多 → 复制实例」打开命名输入，默认「<源名称> 副本」且可修改；确认后走 `instance.duplicate`，不复制日志目录与 `instance.json`、保留实例级 `overrides`；成功后 Toast 提示并刷新列表与选中项，失败时说明原因且不留下半个实例。
- 空态：创建第一个实例。

### 6.3 Download

- 结构：页头 → 来源 chips → 分类 Tab（游戏版本 / Mod / 整合包 / 资源包 / 光影）→ 搜索与结果 → 底部下载队列条。
- 浏览是主任务：点击结果行进入项目整页；页头返回按钮回到原来的搜索页，搜索词、结果与滚动位置都不丢失。页内宽窗为「概览/画廊/描述 + 版本列表」左右两栏，窄窗按同一顺序单列铺开；**不使用下载/安装弹窗，也不再挤在 380px 侧板里**。
- 结果行：图标、名称、作者、下载量、兼容标签；行尾下载按钮直接打开项目页并定位到版本列表。
- 安装一律提交后台任务：点击版本后提示“已加入下载队列”，页面保留以便继续挑选版本；进度、速度、取消都在任务中心，安装完成/失败用 Toast 告知。
- 版本 Tab 的“使用此版本”只负责创建实例表单，随后把游戏文件下载交给后台队列，不再弹进度框。
- 安装前仍需说明目标实例与依赖补全（`includeDependencies`），但不阻塞浏览：缺实例/缺加载器时用 Toast 说明并保持页面可用；切换实例会按新的游戏版本/加载器重新列出兼容版本。

### 6.4 Accounts

- 当前账户卡：头像、名称、类型、正版/离线状态。
- 账户列表：切换、刷新、登出、删除。
- 添加账户：微软 device code / 离线 / 第三方 authlib。
- 不显示 token；只显示状态与过期时间。

### 6.5 Settings

- 分组：外观、启动、下载、存储、Java、任务与日志、通知、关于。
- 外观：单列分组平铺，不再使用“个性化 / 语言与区域”二级页签。分组顺序为 主题（浅色/深色/跟随系统）、主题色（跟随系统：Linux 优先用 KDE `kdeglobals` / GNOME `accent-color`，再回退 XDG Portal；或自定义 + 色板与取色器）、界面（全局着色、界面密度、减少动效、关闭窗口时最小化到托盘、恢复默认外观）、语言与区域；每组为“小标题 + 细线分隔的行 + 可选说明”，行内使用 34×34 图标徽章、标题/副标题与右侧分段控件或开关，不额外套卡片容器。
- 启动：游戏窗口分组（全屏开关、窗口尺寸预设 854×480 / 1280×720 / 1600×900 / 1920×1080，异常值原样回显）与附加游戏参数；窗口设置写入原版 `--width` / `--height` / `--fullscreen` 参数，由 C# `settings.json` 持有。
- 任务与日志：任务中心保留条数（6/12/24/40，仅界面偏好）、日志查看器默认行数（200/400/800/1200）、每实例日志保留数量（5/10/20）与总量上限（16/32/64 MiB，由 C# 启动流程执行裁剪），以及“清理启动日志”（`launch.logs.clear`，保留运行中的日志）。
- 通知：桌面通知总开关与下载完成通知，走系统通知中心；关闭后不再调用 `system.notify`。
- 下载：在来源、并发、每站点连接与代理之外，提供大文件分片阈值（关闭 / 1 / 4 / 8 MiB）与分片大小（256 KiB / 512 KiB / 1 / 2 / 4 / 8 MiB，默认 4 MiB）。
- 存储：实例根列表与数据目录/实例目录入口之外，提供「清理未完成的下载」（`maintenance.cleanPartials`）；确认弹窗说明只删除超过 3 天未更新的 `.part` 临时文件，执行后 Toast 汇总删除文件数与释放体积，没有可清理项时提示无需清理。
- 外观：界面分组额外提供 Toast 停留时长（2/3/5/8 秒）。
- 启动页：界面分组提供启动页选择（主页 `/`、实例 `/instances`、下载 `/download`、账户 `/accounts`、Wiki `/wiki`、设置 `/settings`，默认 `/`）；纯 Flutter 偏好，存 `shared_preferences` 的 `ui.startPage`，下次启动生效，不做即时跳转。
- 关闭行为：界面分组提供「关闭窗口时最小化到托盘」开关（`shared_preferences` 的 `ui.closeToTray`，默认关闭）；开启后点关闭只隐藏窗口，下载/任务继续，退出走托盘菜单「退出」。
- 危险操作单独分区，二次确认。
- 关于：版本、模块版本、许可证、源码获取方式、诊断导出；“检查更新”入口置于关于页最底部（免责声明之后），行内显示当前版本，点击走 `update.check`——无更新时 Toast 提示已是最新，有更新时弹窗展示当前/最新版本与说明，并可打开 release 页面（`system.openUrl`）；只检查，不自动下载或安装。

### 7.1 图标规则

- 品牌标识与加载器标识仍用 `assets/icons/loaders/` 的位图，不用户图标代替。
- 字形集是仓库自带的子集字体，运行与构建都不联网：`tool/icons/tabler-icons.txt` 登记 → `./tool/build-icons.sh` 生成字体与 Dart 表 → 在 `AppIcons` 起语义名。校验用 `python3 tool/check_icons.py`。
- 仓库只提交**打包好的子集字体**（`assets/fonts/AppIcons.ttf`）与生成的字形表；上游图标集、上游 webfont 与逐图标 SVG 不入库，下载缓存落在被忽略的 `app/.cache/`。
- 致谢与许可：关于页“特别致谢”列出 Tabler Icons，许可正文随包分发并在应用内许可页可见；同目录 `SOURCES.md` 记录来源、版本与改动说明。

## 8. 可访问性与 i18n

- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1。
- 键盘可达：Tab 顺序、焦点环、Esc 关闭浮层。
- 读屏：按钮有语义标签；图标按钮有 tooltip。
- 150%/200% 缩放不截断；中文长文本换行。
- 文案全部走 ARB；不拼句子；模型层不保存 UI 文案。
- 设置页左侧分区导航固定，不随内容滚动；仅右侧内容区自行滚动；分区切换不使用额外的内容数量动画，避免与页面切换动画冲突。
- 页面切换快照使用等比宽度绘制（`BoxFit.fitWidth`，顶部对齐），底栏高度变化时不能拉伸旧页快照；切换页面的轻微形变按回归 bug 处理。
- 下载页项目图标和画廊使用 `AppNetworkImage`，加载/失败显示中性占位；画廊点击进入可缩放的图片预览。
- 原版版本下载在 `versions/` 父目录下自动使用共享的 `libraries/`、`assets/`、`versions/`；实例目录仍作为隔离的 gameDir。实例创建提供“版本隔离”选项。
- 所有 `download.execute` 进度经 C# 模块 ABI v2 进度回调进入 C++ taskProgress，Dart 任务中心显示真实字节进度和速度。
- 实例创建和 Forge/NeoForge 安装弹窗的加载器版本字段打开可搜索版本列表，展示最新/推荐/测试标记，允许选择旧版本。
- 全局 Toast 位于标题栏下方居中，使用斜切角面板与类型色边框；最多 5 条，自动消失，不阻断页面操作。
- 账户皮肤使用 `lib/widgets/accounts/skin_preview.dart` 的 2D 纸娃娃预览（头/身体/四肢从 64×64 或 64×32 skin atlas 裁切）；离线/无皮肤账户使用原创默认皮肤 `assets/skins/default-offline.png`，并标注“默认外观”。
- 加载器图标全部使用 `assets/icons/loaders/` 素材：原版为 Wikimedia 草方块（PD），Fabric/Quilt 为 Apache-2.0，Forge/NeoForge 为 LGPL-2.1；来源与许可证记录在同目录 `SOURCES.md`。
- 语言偏好使用系统 / English / 简体中文，切换后立即全局生效。
- 动效可关闭；减少动画时保留状态变化。

## 10. 实施阶段

### Phase 1 · 壳（当前）

- 设计令牌 + ThemeExtension
- AppShell：TopBar + Content + Bottom CommandBar
- 5 个页面骨架 + 真实实例/账户/设置数据
- 空态/骨架屏/错误态基础组件
- 平铺区块 + 直角分隔线 + 纯色背景
- 明暗主题 + 中英文

**验收**：`flutter run` 能看到完整壳；6 个页面可切换；CommandBar 在窄屏收成图标；首页无底栏启动按钮；首页进入其他页面使用覆盖，其他页面之间使用上浮淡入，切回首页使用收回；首页底栏高度用 220ms 动画收至 46。

### Phase 2 · 真实窗口

- `window_manager` / 平台 C++：无边框、拖动、双击最大化、窗口控制按钮
- Windows Mica/Acrylic；Linux 合成器模糊；失败回退
- 背景图/模糊缓存

### Phase 3 · 真实数据

- 接 `CoreClient`：实例列表、下载、账户、设置
- 任务中心接真实 taskId/进度/错误
- 骨架屏替换 mock

### Phase 4 · 打磨

- 图片取色、主题预设、3D 皮肤、通知、设置细化
- 性能与无障碍回归
