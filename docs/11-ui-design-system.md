# 11 · UI 设计系统与 AppShell 规范

> **状态**：Draft v1 · 2026-10-20；**Phase 1 已落地**（AppShell + 5 个页面骨架 + 设计令牌）
> **定位**：Flutter UI 的设计契约。实现以本文的 token、布局和组件规则为准。
> **参考**：仅使用原创设计与通用视觉原则；不包含第三方闭源软件的资产或分析材料。
> **边界**：LauncherX / BakaXL 等仅作为高层布局与信息架构参考；**不复制**其代码、XAML、图标、插画、文案、字体或像素级布局。

---

## 0. 设计立场

ArchoeraCX 的 UI 目标不是“像 LauncherX”，而是：

> **干净、留白、有层次、可长时间使用；背景可以有个性，但内容永远优先。**

我们借鉴 LauncherX 的四件事：

1. **令牌化主题**：颜色/字号/动效/阴影不散落在页面里。
2. **窗口级层次**：标题栏、导航、内容、底栏、浮层各司其职。
3. **背景图层栈**：纯色/图片/Mica/Acrylic + 装饰形状，但始终可退化为纯色。
4. **克制的动效**：页面切换与列表反馈短、轻、可关闭。

我们**不**做：

- 像素级复刻 LauncherX 的任何页面；
- 使用 DINPro 或 LauncherX 的图标/插画/文案；
- 把品牌色定成 LauncherX 的黄色；
- 为了“像”而牺牲可读性、性能或跨平台一致性。

---

## 1. 视觉方向

| 关键词 | 落地 |
|---|---|
| 干净 | 大面积留白、低对比度分隔线、少量边框 |
| 层次 | 背景 → 平铺区块 → 浮层，最多 3 层 |
| 轻量 | 阴影少而软；优先用背景色差而不是重阴影 |
| 个性 | 背景图/渐变/装饰形状可选；默认仍可读 |
| 克制 | 动效 120–240ms；不做弹跳、闪烁、夸张缩放 |
| 可退化 | Mica/Acrylic/模糊失败时回退纯色，不白屏 |

**默认品牌色**：`#4F7CFF`（Archoera Blue）。
LauncherX 的暖黄只作为“可选主题”存在，不作为默认品牌识别。

## 2. 设计令牌

实现位置：`app/lib/theme/tokens.dart`，通过 `ThemeExtension` 暴露给页面。

### 2.1 颜色

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `accent` | `#4F7CFF` | `#7A9BFF` | 主按钮、选中态、链接 |
| `accentHover` | `#6B90FF` | `#94AEFF` | hover |
| `accentPressed` | `#3D66E0` | `#5F82E6` | pressed |
| `accentSoft` | `#4F7CFF1F` | `#7A9BFF26` | 选中背景、浅色标签 |
| `onAccent` | `#FFFFFF` | `#0B1020` | 强调色上的文字 |
| `bg` | `#F7F8FB` | `#10141B` | 窗口底色 |
| `surface1` | `#FFFFFF` | `#171D26` | 浮层/输入底色 |
| `surface2` | `#F1F3F8` | `#1E2632` | hover/次级表面 |
| `surface3` | `#E8EBF3` | `#27313F` | 浮层/输入框 |
| `textPrimary` | `#111827` | `#F2F5FA` | 标题/正文 |
| `textSecondary` | `#4B5563` | `#AAB5C6` | 说明 |
| `textTertiary` | `#8A94A6` | `#738094` | 辅助/占位 |
| `danger` | `#D64545` | `#FF7A7A` | 错误/危险操作 |
| `success` | `#2F9E6B` | `#54D39A` | 成功/在线 |
| `warning` | `#B7791F` | `#F0B45A` | 警告 |
| `border` | `#E3E7EF` | `#2A3442` | 分隔线/边框 |
| `borderStrong` | `#CFD6E4` | `#3A4759` | hover/聚焦 |
| `overlay` | `#00000066` | `#000000A6` | 遮罩 |

> 页面不得直接写十六进制颜色；必须引用 token 或 `ColorScheme`。

### 2.2 字号与字重

| 令牌 | 字号/行高 | 用途 |
|---|---|---|
| `display` | 32 / 40 | 首页大标题、空态主标题 |
| `title1` | 24 / 32 | 页面标题 |
| `title2` | 18 / 26 | 区块标题 |
| `body` | 14 / 22 | 正文 |
| `bodyStrong` | 14 / 22 · 600 | 强调正文 |
| `caption` | 12 / 18 | 辅助说明、元信息 |
| `overline` | 11 / 16 · 600 · 0.6 | 分组标签、chip |

- 默认字体：**Noto Sans SC Medium**（OFL，随应用打包）。
- 所有正文、标题、按钮默认使用 `FontWeight.w500`；层级靠字号、颜色和间距表达，不依赖粗体。
- 拉丁与中文统一使用 Noto Sans SC，避免中英文回退字体不一致。
- **不使用 DINPro**。
- 数字/路径/哈希：等宽字体（`JetBrains Mono` 或系统 monospace）。

### 2.3 间距

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`

| 场景 | 值 |
|---|---|
| 图标与文字 | 8 |
| 区块内边距 | 16–24 |
| 行内边距 | 8–12 |
| 页面边距 | 32（窄屏 16–24） |
| 区块间距 | 16–24 |

### 2.4 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `radiusS` | 2 | chip、输入框、状态标签 |
| `radiusM` | 4 | 按钮、可点击行 |
| `radiusL` | 4 | 浮层 |
| `radiusXL` | 6 | 对话框 |
| `bevelS` / `bevelM` / `bevelL` | 8 / 14 / 22 | 面板与弹窗的斜切角 |
| `radiusFull` | 999 | 仅头像/进度条等天然圆形 |

> 页面级分组优先使用**直边 + 斜切角（钝角）+ 1px 分隔线**，不使用装饰性圆角卡片。斜切角用于 Hero、快捷条、实例块和弹窗；按钮只保留 2–4px 小圆角。

### 2.5 阴影与边框

- 优先边框 + 背景差；阴影只用于浮层/下拉/任务中心。
- Light：`0 8 24 rgba(17,24,39,0.08)`；Dark：`0 8 24 rgba(0,0,0,0.35)`。
- 页面区块默认无填充、无阴影；用 1px 上下分隔线建立层次。
- 列表行 hover 只改 `surface2`，不做位移、不缩放。

### 2.6 动效

| 令牌 | 值 |
|---|---|
| `fast` | 120ms |
| `normal` | 180ms |
| `slow` | 240ms |
| `curve` | `Curves.easeOutCubic` |
| `curveIn` | `Curves.easeInCubic` |

规则：

- 页面切换：淡入 + 8px 上移，180ms。
- 底部导航选中：背景/文字颜色过渡 120ms。
- 列表 hover：只改背景/边框，不位移、不缩放。
- 弹层：120ms 淡入 + 轻微上移。
- 提供“减少动画”开关；关闭后只保留淡入淡出。
- 不在动画中改变 `width/height/margin`，优先 `opacity/transform`。

## 3. 窗口结构

### 3.1 桌面主窗口

```
┌────────────────────────────────────────────────────────────────────┐
│ TopBar     品牌                                                 56     │
├────────────────────────────────────────────────────────────────────┤
│ Content    页面标题 + 操作区                                       │
│            max-width 1400，页面切换淡入 + 8px 上移                │
│            平铺区块 / 表格行 / 列表 / 空态（直角 + 分隔线）        │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│ CommandBar 主导航（左） · 账户 + 启动（右）                72     │
└────────────────────────────────────────────────────────────────────┘
```

- 主窗口采用**全宽底部命令栏**，不使用左侧栏或浮动圆角 Dock。
- 页面标题放在内容区；TopBar 只保留品牌，不放置占位任务/通知等调试入口。
- 命令栏左侧是主导航，右侧是账户与启动按钮；当前实例只作为启动目标，不再占用底栏。
- 导航选中态使用**2px 下划线 + 强调色文字**，不使用圆角底板。
- 宽屏显示账户名与导航文字；窄屏收成图标，超窄屏只保留账户头像和启动图标。
- **Phase 1** 使用系统窗口装饰；后续接 C++/平台能力后再做无边框与 Mica/Acrylic。

### 3.1.1 页面布局

| 页面 | 布局 |
|---|---|
| Dashboard | 快速启动 Hero + 单行快捷入口 + 最近实例网格；不展示核心/Java 调试卡 |
| Instances | 搜索/计数栏 + 平铺实例行列表（左侧 2px 选中条）；每行“更多”提供加载器安装/更新、Mod 管理（启停/删除） |
| Download | 来源选择 + 分类 Tab + 搜索/结果区，内容区独立滚动 |
| Accounts | 当前账户 Hero + 全宽账户列表；空态合并为单个添加账户面板 |
| Settings | 左侧分区导航 + 右侧平铺设置组；Java 分区保持运行环境分组；窄屏切为顶部横向 Tab |

### 3.2 页面信息架构

| 路由 | 页面 | 主要内容 |
|---|---|---|
| `/` | Dashboard | 快速启动、当前账户/实例/下载快捷入口、最近实例 |
| `/instances` | Instances | 实例列表、筛选、创建/导入入口 |
| `/download` | Download | 版本、全局 Mod、整合包、资源包、光影（Tab） |
| `/accounts` | Accounts | 账户列表、添加账户、当前账户 |
| `/settings` | Settings | 通用/外观/Java/网络/合规/关于 |
| overlay | Task Center | 下载/安装队列、暂停/取消 |
| overlay | Notifications | 成功/失败/更新提示 |

### 3.3 底栏 CommandBar

- 左：五个主导航项，图标 + 文字；选中项用 2px 下划线，不填充整块。
- 右：当前账户头像/名称 + 启动按钮，中间用 1px 竖线分隔。
- 当前实例不再显示为独立 chip；未选择实例时启动按钮进入实例页。
- 窄屏只保留导航图标、账户头像与启动图标；所有图标按钮带 tooltip。
- 启动按钮在未选实例时仍可点击，但不会做成无反馈的死按钮。

## 4. 背景系统

### 4.1 图层

```
L0 窗口底色 / 背景图
L1 渐变/装饰形状（最多 3 个）
L2 内容底板（半透明/纯色）
L3 列表/浮层
L4 浮层（对话框/任务中心/通知）
```

### 4.2 类型

| 类型 | 实现 | 回退 |
|---|---|---|
| 纯色 | token `bg` | — |
| 渐变 | 2–3 个低饱和 radial/linear | 纯色 |
| 图片 | 解码到接近窗口尺寸，缓存 | 纯色 + 占位 |
| Mica | Windows DWM（Phase 2） | 半透明/纯色 |
| Acrylic | Windows/Linux 合成器（Phase 2） | 半透明/纯色 |

- 背景图不直接铺 4K；先缩小解码。
- 模糊只在背景切换/窗口尺寸变化时重算，不每帧做。
- 浅色主题叠加图片时必须加蒙版/提高内容底板不透明度，保证正文对比度 ≥ 4.5:1。
- Phase 1 只做**渐变 + 装饰形状**，不做实时模糊。

### 4.3 图片取色（Phase 3）

- 缩放到 64×64 后量化；
- 过滤过亮/过暗/低饱和；
- 按“人口 × 对比度”评分选主色；
- 派生 hover/pressed/soft/onAccent；
- 失败时回退品牌色，并提示“无法从图片取色”。

## 5. 组件规范

### 5.1 按钮

| 类型 | 用途 | 规则 |
|---|---|---|
| Primary | 启动、安装、确认 | 强调色填充；高度 40–44 |
| Secondary | 取消、次要操作 | `surface2` + 边框 |
| Ghost | 标题栏/列表操作 | 透明背景，hover 才出现 |
| Danger | 删除/清空 | `danger` 文本或填充；二次确认 |

- 图标按钮必须有 tooltip。
- 禁用态保持可读；用说明代替“灰掉不解释”。

### 5.2 区块与分隔线

- 页面级内容使用 `AppSection`：透明背景、直角、上下 1px 分隔线。
- 只在浮层、对话框、输入控件和状态标签上使用圆角。
- 多列信息用竖分隔线组织，不嵌套卡片。
- 区块内边距 16–24；标题与内容间距 8–12。

### 5.3 列表项

- 高度 56–72；左侧图标/头像，中间标题+副标题，右侧状态/操作。
- 选中：`accentSoft` 背景 + `accent` 左边 2px 指示条。
- hover：`surface2`。
- 不做整行缩放。

### 5.4 骨架屏

- 用于实例列表、搜索结果、下载队列。
- 形状与最终内容一致； shimmer 缓慢、低对比。
- 超过 300ms 才显示，避免闪烁。

### 5.5 空态 / 错误态

```
[图标]
主标题（一句话）
说明（为什么 + 下一步）
[主操作] [次操作]
```

- 错误态必须包含：原因、可重试动作、查看日志/诊断入口。
- 不用只弹 toast 处理页面级错误。

### 5.6 任务中心

- 右侧抽屉或底部面板；不占页面路由。
- 每个任务：图标、标题、阶段、进度、速度、取消/暂停。
- 失败任务：错误码 + 重试 + 查看日志。
- 任务完成后保留最近 N 条，可清理。

### 5.7 对话框 / 通知

- 危险操作：标题、影响说明、确认短语/勾选、主次按钮同视觉权重。
- 通知：右下角，3–5s 自动消失；错误通知不自动消失。
- 不用全屏遮罩做普通提示。

## 6. 页面草案

### 6.1 Dashboard

- 顶部：大面积快速启动 Hero（实例名、版本/加载器/Mod/最后游玩、启动/查看全部）。
- 快捷条：当前账户、实例数量、浏览内容，三个入口共用一条直线分隔带。
- 最近实例：最多 4 个斜切角实例块，点击切换当前实例；不再堆叠工作区/账户/快捷操作三列。
- 不展示核心桥接、Java 扫描等调试卡片；Java 管理留在设置页。
- 空态：创建实例 / 导入整合包。

### 6.2 Instances

- 顶部：搜索、筛选（版本/加载器）、排序、创建/导入。
- 列表/网格切换；默认列表。
- 每项：图标、名称、版本、加载器、Mod 数、最后游玩、启动/更多。
- 空态：创建第一个实例。

### 6.3 Download

- Tab：游戏版本 / 加载器 / Mod / 整合包 / 资源包 / 光影。
- 顶部筛选：游戏版本、加载器、分类、排序。
- 结果行：图标、名称、作者、下载量、兼容标签。
- 安装前展示依赖/冲突/体积。

### 6.4 Accounts

- 当前账户卡：头像、名称、类型、正版/离线状态。
- 账户列表：切换、刷新、登出、删除。
- 添加账户：微软 device code / 离线 / 第三方 authlib。
- 不显示 token；只显示状态与过期时间。

### 6.5 Settings

- 分组：通用、外观、Java、网络、下载、合规、关于。
- 外观：主题（系统/浅/深）、强调色、背景、动效开关。
- 危险操作单独分区，二次确认。
- 关于：版本、模块版本、许可证、源码获取方式、诊断导出。

## 8. 可访问性与 i18n

- 正文对比度 ≥ 4.5:1；大字号 ≥ 3:1。
- 键盘可达：Tab 顺序、焦点环、Esc 关闭浮层。
- 读屏：按钮有语义标签；图标按钮有 tooltip。
- 150%/200% 缩放不截断；中文长文本换行。
- 文案全部走 ARB；不拼句子；模型层不保存 UI 文案。
- 设置页左侧分区导航固定，不随内容滚动；仅右侧内容区自行滚动。
- 账户皮肤使用 `lib/widgets/accounts/skin_preview.dart` 的 2D 纸娃娃预览（头/身体/四肢从 64×64 或 64×32 skin atlas 裁切）；离线/无皮肤账户使用原创默认皮肤 `assets/skins/default-offline.png`，并标注“默认外观”。
- 加载器图标全部使用 `assets/icons/loaders/` 素材：原版为 Wikimedia 草方块（PD），Fabric/Quilt 为 Apache-2.0，Forge/NeoForge 为 LGPL-2.1；来源与许可证记录在同目录 `SOURCES.md`。
- 语言偏好使用系统 / English / 简体中文，切换后立即全局生效。
- 动效可关闭；减少动画时保留状态变化。

## 10. 实施阶段

### Phase 1 · 壳（当前）

- 设计令牌 + ThemeExtension
- AppShell：TopBar + Content + Bottom CommandBar
- 5 个页面骨架 + 真实实例/账户/设置数据
- 空态/骨架屏/错误态基础组件
- 平铺区块 + 直角分隔线 + 渐变背景
- 明暗主题 + 中英文

**验收**：`flutter run` 能看到完整壳；5 个页面可切换；CommandBar 在窄屏收成图标；页面切换有 220ms 淡入/上移动效。

### Phase 2 · 真实窗口

- `window_manager` / 平台 C++：无边框、拖动、双击最大化、窗口控制按钮
- Windows Mica/Acrylic；Linux 合成器模糊；失败回退
