# 登录、隐私与发行地区法律评估（工作底稿）

> 本文是工程与产品决策底稿，**不构成法律意见**。发行地区、是否运营在线服务、
> 是否收费、是否面向未成年人，都会改变结论。公开分发前应由执业律师按实际
> 发行地、主体和商业模式复核。

## 1. 假设范围

- 主要面向中国大陆个人用户分发桌面启动器；
- 不运营 Minecraft 服务器，不提供游戏内购、账号租售或代练；
- 只提供本地客户端管理、官方账户登录、官方/公开源下载和本地启动；
- 在线启动接口预留，但当前未启用；
- 发布版要求先登录已验证的 Microsoft/Minecraft 账户，之后才允许离线账户。

若未来运营服务器、提供联机服务、接入第三方认证站或收费，需重新评估。

## 3. 关键判断

### 3.1 启动器不等于自动成为“网络游戏企业”

仅提供本地启动、文件管理和官方账户认证，通常更接近工具软件；但如果产品：

- 运营或代运营服务器；
- 提供在线联机、匹配、充值、账号交易；
- 向用户提供未经授权的游戏内容下载；
- 以平台形式向未成年人持续提供游戏服务；

就可能被纳入“网络游戏服务提供者/平台”的监管范围，从而触发实名、防沉迷、
出版/版号、未成年人保护等义务。**不能仅凭“叫启动器”就认为不适用。**

### 3.2 个人信息保护是确定的

无论是否被认定为游戏服务提供者，只要处理 Microsoft UUID、用户名、皮肤、
Xbox XID、令牌、IP、设备路径或日志，就应遵守个人信息保护要求：

- 目的明确、最小必要；
- 有隐私政策与显著告知；
- 需要同意的场景取得同意，并支持撤回；
- 未满 14 周岁用户取得监护人同意，制定专门处理规则；
- 跨境提供（Microsoft/Xbox/Minecraft Services 在境外）需评估并履行适用程序；
- 采取加密、访问控制、日志脱敏等安全措施；
- 支持查阅、复制、更正、删除等权利。

ArchoeraCX 当前采用本地处理、无自有后端、令牌加密存储、日志不记录令牌，
这些是必要基础，但不等于自动满足全部告知/同意/跨境/未成年人要求。

### 3.3 未成年人保护需要产品化

《未成年人网络保护条例》第 46、47 条对网络游戏服务提供者提出真实身份验证、
防沉迷和适龄提示要求。启动器本身不直接运营游戏，但若提供在线游戏服务，风险
会显著上升。

因此：

- 不面向未成年人做营销；
- 隐私政策明确未满 14 周岁需监护人同意与指导；
- 不收集身份证号、人脸等实名信息（当前也没有此功能）；
- 若未来启用在线服务，先完成实名/防沉迷/适龄提示/监护人机制，再上线；
- 不对未成年人提供账号租售、代练、充值等入口。

### 3.4 游戏文件与出版/版号风险

在线下载 Minecraft 客户端与资源、分发第三方 Mod/整合包会涉及著作权、平台
条款和出版监管的不确定性。项目既有的 `official-cn` L0 策略（默认不下载内容）
是降低风险的工程方向；但当前代码尚未完整实现构建期合规门控，不能对外宣称
“已符合某部法律”。发行前应把构建通道、默认等级和实际能力做成可审计的一致
状态，并由律师复核。


### 3.5 其它启动器的隐私处理参考

以下只比较公开可见的做法，不复制其文本或代码：

| 项目 | 公开做法 | 本项目取舍 |
|---|---|---|
| Prism Launcher | 数据保存在本机；不向自有服务器上传；关闭更新检查后不主动联网 | 采用“本地优先”，不新增遥测/云同步；下载和登录仍按用户操作直连第三方 |
| Modrinth App | 明确列出收集类别、第三方处理者、用户权利和跨境；账号与内容服务有完整隐私文档 | 采用分类、第三方清单、权利与删除章节；不引入其账号/云功能 |
| Dawn Launcher | 将启动结果、系统信息和可选的 support bundle 分类说明，区分自动遥测与显式上传 | 当前不自动上传；本地日志与后续可选诊断必须明确区分 |
| HMCL / PCL2 | 账户凭据本地加密；不提供云端账户同步；对敏感配置和日志较谨慎 | 继续本地加密保险库，不做云账户，不把日志上传作为默认行为 |

共同点：**默认本地、默认不收集、第三方服务单独披露、用户可删除本地数据**。
这与当前 PRIVACY.md 的方向一致。

参考链接：Prism Launcher 隐私说明
<https://github.com/PrismLauncher/prismlauncher.org/issues/110>；
Modrinth 隐私政策 <https://modrinth.com/legal/privacy>；
Dawn Launcher 隐私政策 <https://dawn.gg/privacy>。

### 3.5.1 本项目明确不做

- 不做广告 SDK、行为分析、设备指纹；
- 不做云端账户同步或云端实例同步；
- 不默认上传崩溃报告、日志或 Mod 列表；
- 不把 Microsoft/Minecraft token 发送到自有服务器；
- 不把第三方站点内容镜像后冒充官方。

## 4. 登录部分的产品决定

### 4.1 发布版

1. **必须先登录已验证的 Microsoft/Minecraft 账户**，之后才允许添加、选择
   或使用离线账户。
2. 离线账户只作为本地测试/单人用途，不冒充正版，不进入在线认证。
3. **暂不开放第三方 authlib/Yggdrasil 登录**，直到完成服务条款、隐私、实名
   与安全复核。
4. 不在客户端内提供账号租售、共享、代练或绕过正版验证的功能。
5. 在线启动接口保留，但当前返回 `ONLINE_LAUNCH_NOT_READY`；在完成
   entitlement、certificates、令牌消费和合规复核前不向用户开放。
6. 发布版若没有已验证 Microsoft 账户，启动请求返回
   `PREMIUM_ACCOUNT_REQUIRED`；开发版保留测试便利。
7. 不把本地门控宣传为“法律合规”或“防破解”；它只是产品默认值和意图记录。

### 4.2 调试版

- 允许离线账户，便于 UI/启动测试；
- 不得用于公开分发；
- 发布构建必须使用 Release 配置并走正版门槛。

### 4.3 在线启动预留

`launch.prepare` 已提供稳定的准备接口，返回：

```json
{
  "instanceId": "...",
  "mode": "online",
  "ready": false,
  "reason": "ONLINE_LAUNCH_NOT_READY",
  "requiresEntitlement": true,
  "requiresCertificates": true,
  "accountKind": "microsoft"
}
```

`launch.start` 接受 `mode` 参数；在线模式当前返回明确的“未就绪”错误，而不是
把在线账户当成离线启动。后续接入 `/entitlements/mcstore`、证书和令牌时，
不改变现有 Dart/C++ 方法名。


### 4.4 中国大陆构建的下载默认关闭

中国大陆发行构建默认禁用在线下载，但保留用户手动解锁路径：

- `compliance.json` 中要求 `developerMode=true`、`acceptRisk=true`、
  `downloadLevel="L2"`、`acknowledgement="ENABLE-DOWNLOADS 1"`；
- 默认隐藏下载入口；直接访问 `/download` 可查看配置路径和缺失字段；配置完成后重启应用显示下载页；
- C# 在资源/版本/加载器下载方法入口统一检查，未解锁返回
  `DOWNLOAD_DISABLED`；Flutter/C++ 不使用地区探测；
- 登录、实例管理、本地启动和本地 Mod 管理不受影响。

这是风险门槛和产品默认值，不是法律合规认证；解锁后用户仍需自行承担第三方
内容、平台条款和版权风险。


### 4.5 非中国大陆地区：仅微软验证账户

非中国大陆构建/运行环境通过粗粒度 IP 国家码与系统语言/时区判断地区。区域不为
中国大陆时：

- 添加账户只显示微软登录；
- 离线账户不能添加、选择或启动；
- 第三方 authlib 暂不开放；
- 在线启动仍处于预留状态，微软账户启动返回 `ONLINE_LAUNCH_NOT_READY`。

IP 查询只读取 Cloudflare trace 的两位国家码，不保存 IP；失败时使用系统语言/
时区。可用 `ARCHOERACX_REGION=CN|GLOBAL` 做开发覆盖。该检测不是 VPN/代理的
安全边界，也不能替代账号服务端的真实校验。

#### 与 HMCL 的差异（行为参考）

HMCL 当前版本（GPLv3，仅阅读行为，不复制代码）使用同一发行版：

- **账户限制看机器地区**：`Asia/Shanghai` 或 UTC+8 + 系统国家/Windows GeoID
  判为中国大陆；大陆默认允许离线；非大陆默认禁用离线与 authlib-injector
  的创建，提示登录微软；登录微软后会自动打开 `enableOfflineAccount`。
- **网络地区看 IP**：`ipwho.is` 只用于中国大陆下载限制/镜像选择；不用 IP
  判断账户地区。
- **登录流程不按地区分叉**：浏览器授权码优先，设备码作为可选方式。

因此 HMCL 的非大陆策略是“微软登录后解锁离线”，不是“只能微软账户”。
ArchoeraCX 按当前产品要求采用更严格的规则：非大陆不提供离线解锁；IP 优先、
系统地区兜底；微软在线启动完成前返回 `ONLINE_LAUNCH_NOT_READY`，不会静默
降级为离线启动。
